# TTS Studio

Приложение для синтеза речи на русском языке с поддержкой пакетной обработки, расстановкой ударений, эквалайзером и шумоподавлением.

## Возможности

- **Синтез речи** на основе Silero TTS
- **Расстановка ударений** через RUAccent (fast/accurate)
- **Пакетная обработка** текстовых файлов
- **Эквалайзер** (7 полос: 80, 200, 500, 1000, 2000, 4000, 8000 Hz)
- **Шумоподавление LogMMSE** (настраиваемые параметры)
- **Нормализация громкости** (loudnorm)
- **Сохранение в MP3/WAV** с настраиваемым битрейтом
- **Аудиоплеер** для прослушивания результатов
- **Автосохранение настроек** между сессиями

```bash
sudo apt update

Создание виртуального окружения
bash

python3 -m venv myenv
source myenv/bin/activate

Установка Python зависимостей
bash

pip install torch torchaudio
pip install ruaccent runorm
pip install PyQt5 PyQt5.QtMultimedia
pip install scipy numpy soundfile pydub

Запуск
bash

python main.py

Структура рабочей папки
text

рабочая_папка/
├── source/           # Исходные текстовые файлы (.txt, .md, .rst)
├── audio/            # Сгенерированные аудиофайлы (.mp3, .wav)
├── logs/             # Логи пакетной обработки
└── cache/            # Кэш моделей

Настройки
Основные
Параметр	Описание
Голос	xenia, aidar, baya, kseniya, eugene
Ударения	fast (turbo2) — быстро, accurate (big_poetry) — точно
Формат	MP3 или WAV
Битрейт	128k, 192k, 256k, 320k
Длина чанка	150-600 символов (для синтеза)
Постобработка
Параметр	Описание
Нормализация	Выравнивание громкости (loudnorm)
LogMMSE	Шумоподавление с настройками: initial_noise, window_size, noise_threshold
Эквалайзер

7 полос с регулировкой от -6 до +6 dB:

    80 Hz (низкий бас)

    200 Hz (гулкость/бубнёж)

    500 Hz (тело голоса)

    1000 Hz (присутствие)

    2000 Hz (разборчивость)

    4000 Hz (сибилянты)

    8000 Hz (воздух/яркость)

Использование
Вкладка "Текст"

    Введите текст вручную или загрузите файл

    Нажмите "Синтезировать речь"

    Прослушайте результат во встроенном плеере

Вкладка "Пакетная обработка"

    Выберите рабочую папку

    Поместите текстовые файлы в папку source/

    Нажмите "Обновить" для сканирования файлов

    Выберите файлы для обработки

    Нажмите "Обработать выбранные"

Горячие клавиши
Комбинация	Действие
Ctrl+O	Открыть файл (вкладка Текст)
Ctrl+Shift+O	Открыть рабочую папку
Ctrl+S	Синтезировать
Ctrl+Shift+S	Остановить синтез
Требования

    OS: Linux (Ubuntu/Debian)

    Python: 3.8+

    RAM: 4 GB (рекомендуется 8 GB для big_poetry)

    CPU: Любой (GPU не требуется)

Компоненты
Компонент	Версия	Назначение
Silero TTS	v4_ru	Генерация речи
RUAccent	1.5+	Расстановка ударений
FFmpeg	7.x	Постобработка аудио
LogMMSE	0.1.7	Шумоподавление
Известные ограничения

    Silero не принимает текст длиннее 1000 символов (текст разбивается автоматически)

    Модель big_poetry требует ~5 GB RAM

    Первый синтез может быть медленным из-за загрузки моделей
